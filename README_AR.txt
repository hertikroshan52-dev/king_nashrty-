TELEGRAM AI PRO — دليل تشغيل النسخة المعدّلة
===========================================

الملف الرئيسي: telegram_ai_pro_main.py
المصدر: main(1).py الذي أرفقه المستخدم، مع إضافة وظائف الإدارة والذكاء الاصطناعي.

ماذا تحتوي النسخة؟
-----------------
1) جميع قوائم الإدارة والردود وتجميع الروابط وبيانات البوت الأصلية.
2) تمت المحافظة على منطق publish_to_groups وstart_publishing وstop_publishing دون تغيير؛
   التغيير الوحيد داخلها هو استخدام بيانات Telegram API الصحيحة بدلاً من قيم تجريبية ثابتة.
3) مساعد ذكاء اصطناعي (استشارات وتحليل وصياغة إعلانات)، يعمل بـ OPENAI_API_KEY.
   المساعد لا ينفذ تعليمات تشغّل الحسابات ولا يرسل الجلسات إلى مزود الذكاء الاصطناعي.
4) قالب الملف الشخصي: اسم وبايو وما يصل إلى 5 صور وتطبيق الخصوصية المدعومة
   وحذف الصور السابقة والقصص المدعومة، عند إضافة حساب جديد إن كان القالب مفعلاً،
   أو يدوياً على حساب واحد أو على حسابات المشرف بعد التأكيد.
5) حفظ روابط مجلدات تيليجرام وحذفها، وإعداد العدد المرجعي 2 أو 5.
   الروابط لا تؤدي إلى انضمام جماعي تلقائي، ولا يجري حذف مجلدات لتجاوز حدود تيليجرام.
6) تسجيل تقارير تجهيز الحسابات في جدول profile_job_history.

قيود مهمة
---------
* لم يتم تغيير إعداد Automatic media download أو Sync Contacts أو Suggest Frequent Contacts؛
  هذه إعدادات تطبيق/جهاز وليست عمليات عامة مضمونة عن طريق جلسة Telethon.
* لم يتم تنفيذ حذف جهات الاتصال المتزامنة دون موافقة مستقلة ومحددة.
* خيارات الخصوصية Messages وGifts قد لا تتطابق مع مفاتيح Telegram API المتاحة،
  ولذلك تسجل النسخة عدم تطبيقها بدلاً من ادعاء نجاح العملية.
* يختلف دعم المفاتيح بحسب تحديث مكتبة Telethon ونوع الحساب.
* لا تحتوي هذه الحزمة على أدوات تبديل حسابات مقيدة أو التحايل على قيود مجموعات تيليجرام.
* لا يمكن تأكيد أن النظام يعمل باستقرار 10/10 قبل تجربة فعلية على بيئتك.

التثبيت (Termux / Ubuntu 24.04 / Python 3.12)
----------------------------------------------
احفظ نسخة احتياطية من مجلد المشروع وقاعدة البيانات والوسائط أولاً.
انتقل إلى مجلد مشروعك الأصلي نفسه، حتى يبقى المسار الافتراضي للبيانات مطابقاً.

  python3 -m venv .venv
  source .venv/bin/activate
  pip install -r requirements.txt

الإعدادات: صدّر المتغيرات التالية في بيئتك الآمنة (لا تضف القيم الفعلية للكود ولا ترفعها علناً):

  export BOT_TOKEN='ضع_توكن_البوت_هنا'
  export OWNER_ID='ضع_ايدي_المالك_هنا'
  export TELEGRAM_API_ID='ضع_API_ID_هنا'
  export TELEGRAM_API_HASH='ضع_API_HASH_هنا'
  export OPENAI_API_KEY='ضع_مفتاح_OpenAI_API_هنا'
  export OPENAI_MODEL='gpt-6'

يمكن تغيير اسم النموذج بحسب النماذج المتاحة في حساب واجهة OpenAI API.
المساعد الذكي يعمل فقط عند توفر المفتاح؛ لا يلزم المفتاح لإدارة الحسابات.

إن كنت تستخدم DATA_DIR أو DB_NAME أوامر export في المشروع القديم، حافظ عليها:
  export DATA_DIR='/path/to/existing/bots_data/your_bot'
  export DB_NAME='/path/to/existing/bots_data/your_bot/bot_database.db'

التشغيل:
  python3 telegram_ai_pro_main.py

مهم: Telegram API_ID و API_HASH تخص تطبيقك في my.telegram.org؛
القيم 1 و b في الملف القديم قيم تجريبية غير مناسبة لتشغيل جلسات حقيقية.

الأمان:
- لا ترسل BOT_TOKEN أو StringSession أو API_HASH أو OPENAI_API_KEY إلى أي محادثة عامة.
- الجلسات في قاعدة البيانات الأصلية مخزنة دون تشفير ظاهر؛ احمِ قاعدة البيانات ونسخها الاحتياطية.
- لا تشغل نسختين من البوت بالتوكن نفسه في الوقت نفسه.
- خزّن ملف الإعدادات ومجلد البيانات بصلاحيات مقيدة، لا تشاركها مع الآخرين.

نتائج التحقق هنا:
- نجاح py_compile وAST.
- نجاح اختبار إنشاء جداول الإضافات وتخزين قالب متعدد الصور وتبديل خيار التشغيل
  وتخزين روابط المجلدات وإعداد العدد.
- مقارنة النص البرمجي أثبتت تطابق منطق النشر الأصلي (باستثناء إنشاء TelegramClient).
- لم يُجر اختبار حي مع Telegram أو OpenAI، لأن مكتبات التشغيل والاتصال الشبكي
  غير متاحين في بيئة الفحص الحالية.
